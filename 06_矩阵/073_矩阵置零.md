# 73. 矩阵置零

**难度：** 中等 · **状态：** 力扣已解答 · [原题](https://leetcode.cn/problems/set-matrix-zeroes/)

## 题目

给定一个 `m x n` 的矩阵，如果一个元素为 **0**，则将其所在行和列的所有元素都设为 **0**。请使用 **原地** 算法。

**示例 1：**

![示例 1：中心的 0 使其所在行和列置零](https://assets.leetcode.com/uploads/2020/08/17/mat1.jpg)

> **输入：** `matrix = [[1,1,1],[1,0,1],[1,1,1]]`  
> **输出：** `[[1,0,1],[0,0,0],[1,0,1]]`

**示例 2：**

![示例 2：两个 0 使第一行、第一列和第四列置零](https://assets.leetcode.com/uploads/2020/08/17/mat2.jpg)

> **输入：** `matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]`  
> **输出：** `[[0,0,0,0],[0,4,5,0],[0,3,1,0]]`

**提示：**

- `m == matrix.length`
- `n == matrix[0].length`
- `1 <= m, n <= 200`
- `-2³¹ <= matrix[i][j] <= 2³¹ - 1`

**进阶：**

- 一个直观的解决方案是使用 `O(mn)` 的额外空间，但这并不是一个好的解决方案。
- 一个简单的改进方案是使用 `O(m + n)` 的额外空间，但这仍然不是最好的解决方案。
- 你能想出一个仅使用常量空间的解决方案吗？

## 我的答案

### 第一版：先记录零的坐标，再清零对应的行和列

```python
class Solution:
    def setZeroes(self, matrix: list[list[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        # 先是找到哪些元素是0元素，然后再强制令行和列是0
        ans = []
        for i in range(len(matrix)):
            for j in range(len(matrix[0])):
                if matrix[i][j] == 0:
                    ans.append([i,j])
        for row,col in ans:
            #现在是对于行清零，是对于所有的列
            for j in range(len(matrix[0])):
                matrix[row][j] = 0
            #现在是对列清零，对于所有的行处理
            for i in range(len(matrix)):
                matrix[i][col] = 0
```

## 我的注释与感悟

- **先找原来的 `0`，把行号和列号一起存进 `ans`，再清零。** 两版都是遇到 `matrix[i][j] == 0` 就存下 `[i, j]`。第一遍不改矩阵，第二遍只根据这份坐标清单操作，新写入的 `0` 就不会触发额外的清零。
- **`for row, col in ans` 用序列解包取出每一对坐标。** `row` 接的是当时存进去的 `i`，`col` 接的是当时的 `j`。比如这轮取到 `[0, 3]`，就相当于 `row, col = [0, 3]`，接下来清零的是下标为 `0` 的行和下标为 `3` 的列。
- **清一行：固定行号，遍历列；清一列：固定列号，遍历行。** `matrix[row][j] = 0` 用 `for` 逐格改这一行；`matrix[i][col] = 0` 则用 `for` 在每一行改同一列的位置。`ans` 只是用来记坐标，真正被修改的是原来的 `matrix`，函数不用返回新矩阵。

## 知识点与评论

### 取整行、取整列，以及 `matrix[0]` 中的 `0`

**`len(matrix)` 是行数，`len(matrix[0])` 是列数。** 这里的 `0` 是第一行的下标：矩阵每行一样长，数一下第一行的元素个数，就知道有几列。它不是「取列时要加的 `0`」。普通的 Python 二维列表按行存放，所以 **取整行可以直接用 `matrix[row]`，取整列则要遍历每一行，从每行取同一个下标 `col`**。

```python
matrix = [[1, 2, 3], [4, 5, 6]]
row, col = 1, 2
print(len(matrix[0]))                  # 3：共有三列
print(matrix[row])                     # [4, 5, 6]：第二行
print(matrix[0][col])                  # 3：第一行第三列的一个元素
print([line[col] for line in matrix])  # [3, 6]：第三列，每行取一个
```

列表推导式里的 `for` 和清零时的 `for` 都是在逐行找同一个列位置，区别是前者**读取并收集**，后者**逐格写入 `0`**。直接写 `matrix[row] = 0` 会把一整行列表换成整数 `0`，破坏矩阵结构；`matrix[, col] = 0` 也不是合法的 Python 写法。

### 为什么先记录，以及两版的复杂度

- **为什么不能边找边清零？** 例如 `[[0,1],[1,1]]`，原本只有左上角是 `0`，正确结果是 `[[0,0],[0,1]]`。如果一看到左上角就清零，右上角也会变成 `0`；随后如果把右上角当成原有的 `0`，就会误清整列，把本应保留的右下角 `1` 也清掉。
- **两版算法相同。** 设 `z` 是原矩阵里 `0` 的个数。第一遍扫描用 `O(mn)` 时间；每个零坐标再清一行和一列，耗时 `O(m + n)`。总时间为 `O(mn + z(m + n))`，额外空间为 `O(z)`，最坏分别为 `O(mn(m + n))` 和 `O(mn)`。第二版注释中提到的「借用矩阵自己的格子」没有用到；实际执行的仍是用 `ans` 保存坐标。
- **可以先把行号和列号去重。** 用两个集合分别记录要清零的行和列，第二遍逐个检查格子，只要它的行号或列号在对应集合里，就写 `0`。这样可以做到 `O(mn)` 时间、`O(m + n)` 额外空间。当前两版已修改原矩阵，但记录坐标的列表仍占额外空间，并不满足进阶的 `O(1)` 空间要求。
