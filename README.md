# LeetCode Hot 100 · Python 刷题训练

从下一题开始，每道题在对应专题目录下单独建一份 Markdown，命名为 `NNN_题名.md`。不需要为了记笔记另建 `.py` 文件。

- **题目**：按原题完整转录，保留题目描述、所有示例及其解释、数据范围和约束，不改写成摘要。
- **我的答案**：保留我的原代码，不用助手的写法替换。
- **我的注释与感悟**：紧接在答案下方，作为独立小节，保留我提供的注释、解题思路和感悟，不塞回代码块；没提供的内容不代写。
- **知识点与评论**：助手另列可能难懂或容易出错的知识点，以及复盘建议。先写要点，哪些需要展开由我另外说明。
