# 438. 找到字符串中所有字母异位词

**难度：** 中等 · **状态：** 力扣已解答 · [原题](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)

## 题目

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**示例 1：**

> **输入：** `s = "cbaebabacd", p = "abc"`  
> **输出：** `[0,6]`  
> **解释：**  
> 起始索引等于 `0` 的子串是 `"cba"`，它是 `"abc"` 的异位词。  
> 起始索引等于 `6` 的子串是 `"bac"`，它是 `"abc"` 的异位词。

**示例 2：**

> **输入：** `s = "abab", p = "ab"`  
> **输出：** `[0,1,2]`  
> **解释：**  
> 起始索引等于 `0` 的子串是 `"ab"`，它是 `"ab"` 的异位词。  
> 起始索引等于 `1` 的子串是 `"ba"`，它是 `"ab"` 的异位词。  
> 起始索引等于 `2` 的子串是 `"ab"`，它是 `"ab"` 的异位词。

**提示：**

- `1 <= s.length, p.length <= 3 * 10⁴`
- `s` 和 `p` 仅包含小写字母

## 我的答案

### 第一版：定长窗口 + 排序比较

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        # 首先对于异位词，肯定是需要进行解码分类组合的。
        left = 0
        s_len  = len(s)
        p_len = len(p)
        ans = []
        P_sorted = "".join(sorted(p))
        if s_len < p_len:
            return []
        for right in range(s_len):
            left = right - p_len + 1
            if P_sorted == "".join(sorted(s[left:right+1])):
                ans.append(left)
        return ans
```

### 第二版：用 `continue` 跳过未凑满的窗口

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        # 首先对于异位词，肯定是需要进行解码分类组合的。
        left = 0
        s_len  = len(s)
        p_len = len(p)
        ans = []
        P_sorted = "".join(sorted(p))
        if s_len < p_len:
            return []
        for right in range(s_len):
            left = right - p_len + 1 #这里当开始的时候，left是负数 然后返回的是空字符串 这样的话下面的条件不满足，自动跳过。并且这样的话不会报错
            # s = "abcdef"
            # print(s[4:2])   # ""
            # print(s[-2:1])  # ""
            if left < 0: #可以加一个这样的条件 手动推出。因为这个p字符串长度是固定的，所以可以这样做。
                continue
            if P_sorted == "".join(sorted(s[left:right+1])):
                ans.append(left)
        return ans
```

## 我的注释与感悟

- **窗口没凑满，就用 `continue` 跳过本轮。** `right` 还是由 `for` 逐个推进；如果算出来的 `left < 0`，说明右边界还没走到第一个完整窗口，所以可以直接进入下一轮，不切片也不排序。比如 `p_len = 3` 时，`right` 为 `0`、`1` 都跳过，到了 `2` 才检查 `s[0:3]`。
- **把异位词变成同一种写法再比较。** 这里不用枚举字符的各种排列。先把 `p` 排序并拼起来，再用同样的方法处理窗口内的子串。比如 `"cba"` 和 `"abc"` 排序后都是 `"abc"`。这沿用了第 49 题用排序生成分组键的思路：**忽略排列顺序，但保留每个字母出现的次数。**
- **用 `for` 逐个枚举右端点 `right`，就能检查每一个完整窗口。** 原解用 `for right in range(s_len)` 从左到右遍历 `s` 的下标。每个能凑满窗口的右端点都对应唯一的左端点，因此不用再单独遍历 `left`。
- **窗口长度固定，左边界直接算。** 异位词的长度一定等于 `len(p)`。窗口包含左右两端，所以 `right - left + 1 = p_len`，反推 `left = right - p_len + 1`。窗口凑满后，`right` 每前进一格，`left` 也跟着前进一格。和第 3 题不同，**这里不用 `while` 收缩左边界。**
- **匹配后记录左边界，不记录子串。** `s[left:right+1]` 取到包含 `right` 的窗口；排序结果相同就把起始下标 `left` 加到 `ans`。

## 知识点与评论

- **负下标不一定产生空切片。** 第一版在 `s_len >= p_len` 且 `left < 0` 时，Python 将切片起点换算为 `s_len + left`，它至少等于 `right + 1`（切片的结束位置），所以在本题里才得到空字符串，不会误匹配非空的 `p`。例如 `"abcdef"[-2:6]` 就不是空串，而是 `"ef"`。第二版显式跳过不完整的窗口；直接用 `range(p_len - 1, s_len)` 则连这些轮次都不用遍历。两种写法都不改变完整窗口的比较逻辑。
- **开销主要来自每次重新排序。** 设 `n = len(s)`、`m = len(p)`。有 `n - m + 1` 个完整窗口，每个都要切片、排序和拼接；当 `n >= m` 时，最坏时间上界为 `O(n + (n - m + 1) · m log(m + 1))`，额外空间为 `O(m)`（不计答案）。
- **相邻窗口只差一进一出。** 题目只包含小写字母，可以用两个长度为 `26` 的数组分别记录 `p` 和窗口的字母频次。窗口每滑一步，只给新进入的字母加 `1`、给移出的字母减 `1`，再比较频次数组。这样不用反复排序，总时间可做到 `O(n + m)`。

## Python 核心知识点：`sort()`、`sorted()`、`split()`、`join()`、`list()`

### 1. `sort()` 与 `sorted()`：排序

**`list.sort()` 修改原列表，返回 `None`；`sorted()` 接受可迭代对象，返回一个排好序的新列表。** 两者都可以用 `reverse=True` 降序排列。

```python
nums = [3, 1, 2]
result = nums.sort()
print(nums)    # [1, 2, 3]
print(result)  # None，所以别写 nums = nums.sort()

s = "cba"
print(sorted(s))                    # ['a', 'b', 'c']，不是字符串 "abc"
print(s)                            # cba，原字符串没变
print(sorted(nums, reverse=True))   # [3, 2, 1]
```

### 2. `split()`：按分隔符拆分字符串

不传分隔符时，`split()` 按空白拆分，连续空白视为一个分隔符。也可以显式指定分隔符，比如逗号。**`split("")` 会报 `ValueError`，不能用它逐字符拆分。**

```python
print("hello   world".split())  # ['hello', 'world']
print("a,b,c".split(","))       # ['a', 'b', 'c']
```

### 3. `join()`：把多个字符串拼在一起

写法是 `分隔符.join(可迭代对象)`。**分隔符可以是空字符串，但参与拼接的元素必须都是字符串。**

```python
chars = ['a', 'b', 'c']
print("".join(chars))    # abc
print(" ".join(chars))   # a b c
print("-".join(chars))   # a-b-c
```

### 4. `list()`：把可迭代对象转换成列表

**要把字符串逐字符拆开，用 `list(s)`；要按分隔符拆成若干段，用 `s.split(...)`。**

```python
print(list("abc"))       # ['a', 'b', 'c']
print(list((1, 2, 3)))   # [1, 2, 3]
```

### 5. 常见组合

**本题：先排序，再拼接成统一的比较键。** `sorted(s)` 保留重复字母，`join()` 只负责把排好序的字符拼回字符串。

```python
s = "cba"
chars = sorted(s)         # ['a', 'b', 'c']
key = "".join(chars)      # "abc"
key = "".join(sorted(s))  # 一行写完，结果同上
```

**ACM 输入：把一行用空白分隔的数字读成整数列表。** `split()` 得到字符串，`map(int, ...)` 逐个转成整数，`list(...)` 再把结果收集成列表。

```python
nums = list(map(int, input().split()))  # 输入：3 1 2
print(nums)                            # [3, 1, 2]
```

**核心记忆：** `sort()` 改原列表，`sorted()` 返回新列表；`split()` 按分隔符拆，`join()` 按分隔符拼；`list(s)` 把字符串拆成单字符列表。
