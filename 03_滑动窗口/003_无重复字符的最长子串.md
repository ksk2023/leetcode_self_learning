# 3. 无重复字符的最长子串

**难度：** 中等 · **状态：** 力扣已解答 · [原题](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

## 题目

给定一个字符串 `s`，请你找出其中不含有重复字符的 **最长子串** 的长度。

**示例 1：**

> **输入：** `s = "abcabcbb"`  
> **输出：** `3`  
> **解释：** 因为无重复字符的最长子串是 `"abc"`，所以其长度为 `3`。注意 `"bca"` 和 `"cab"` 也是正确答案。

**示例 2：**

> **输入：** `s = "bbbbb"`  
> **输出：** `1`  
> **解释：** 因为无重复字符的最长子串是 `"b"`，所以其长度为 `1`。

**示例 3：**

> **输入：** `s = "pwwkew"`  
> **输出：** `3`  
> **解释：** 因为无重复字符的最长子串是 `"wke"`，所以其长度为 `3`。  
> 请注意，你的答案必须是 **子串** 的长度，`"pwke"` 是一个子序列，不是子串。

**提示：**

- `0 <= s.length <= 10⁵`
- `s` 由英文字母、数字、符号和空格组成

## 我的答案

### 第一版：列表记录窗口，用 `len(window)` 计长

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # 这里有一个基本思路 肯定有一个全局变量和局部变量,这里的局部变量我就定义为窗口的长度
        left = 0
        max_length = 0
        window = []
        for right in range(len(s)):
            # window = s[left,right+1]
            while s[right] in window:#如果右侧有重复的，就会不断遍历，找到不重复的，记录此时的窗口长度迭代
                window.remove(s[left])
                left = left + 1
            window.append(s[right]) #如果没有的话 就继续添加

            max_length = max(max_length,len(window))
        return max_length
```

### 第二版：集合判断重复，用 `right - left + 1` 计长

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        left = 0
        window = set()
        ans = 0
        for right in range(len(s)):
            while s[right] in window:# 如果右指针字符在窗口内,就开始收缩左边界.
                window.remove(s[left]) # 把左边的字符直接删除掉
                left += 1
            window.add(s[right])
            ans = max(ans,right - left + 1 )
        return ans

        # 这里的逻辑是,是不会有重复的.因为如果重复是不断循环,但是不会影响最大值.
```

## 我的注释与感悟

**这类滑动窗口通常由外层 `for` 循环逐步推进右边界 `right`，让窗口持续向右遍历。右边界向右推进让窗口扩张，遇到重复时左边界向右推进让窗口收缩，这就是窗口能够伸缩的基础。**

- **`for` 推进右边界，`while` 只收缩左边界。** `right` 随 `for` 一步步往前走。每一轮如果 `s[right]` 已经在窗口里，`right` 先不动，`while` 反复移除 `s[left]` 并推进 `left`，直到旧的重复字符被移出去，才加入 `s[right]`。
- **窗口长度可以直接用两端下标算。** 第一版用 `len(window)`，第二版用 `right - left + 1`。加入 `s[right]` 之后，左右两端都在窗口里，所以要加 `1`。两种写法算的是同一个长度。
- **收缩窗口时不更新历史最大值。** 当前窗口可能变短，但 `max_length` 或 `ans` 不会被重置。等 `s[right]` 加入、窗口确认无重复后，再用 `max(...)` 更新。这里的「全局」指整道题的最大值，不是 Python 的全局变量。

## 知识点与评论

- **为什么用 `while` 而不是 `if`？** 比如 `"abba"` 扫到第二个 `b` 时，窗口是 `"ab"`。只移除左端的 `a` 不够，还得移除旧的 `b`，才能加入新的 `b`。
- **集合不保存顺序，但窗口仍然连续。** 顺序和范围由原字符串的下标决定。加入 `s[right]` 后，窗口对应 `s[left:right + 1]`；`set` 只负责判断哪些字符在窗口里，不需要在每轮真的截取字符串。
- **两版是同一个滑动窗口算法，差别在容器的操作成本。** 两个指针都只往前走，每个字符最多进入和离开窗口一次。设字符串长度为 `n`、最大窗口长度为 `w`：列表版成员查找和左端删除最多需要 `O(w)`，总时间上界为 `O(nw)`；集合版成员查找、添加和删除平均为 `O(1)`，总时间平均为 `O(n)`。两版额外空间均为 `O(w)`，空串都直接返回 `0`。
