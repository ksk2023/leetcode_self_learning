# 11. 盛最多水的容器

**难度：** 中等 · **状态：** 力扣已解答 · [原题](https://leetcode.cn/problems/container-with-most-water/)

## 题目

给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明：** 你不能倾斜容器。

**示例 1：**

![示例 1：蓝色区域表示两条红线之间能容纳的水](https://s3-lc-upload.s3.amazonaws.com/uploads/2018/07/17/question_11.jpg)

> **输入：** `[1,8,6,2,5,4,8,3,7]`  
> **输出：** `49`  
> **解释：** 图中垂直线代表输入数组 `[1,8,6,2,5,4,8,3,7]`。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 `49`。

**示例 2：**

> **输入：** `height = [1,1]`  
> **输出：** `1`

**提示：**

- `n == height.length`
- `2 <= n <= 10⁵`
- `0 <= height[i] <= 10⁴`

## 我的答案

### 第一版：在分支内更新最大面积

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        left = 0
        right = len(height) - 1
        max_area = 0
        while left < right:
            if height[left] <= height[right]:
                cur_area = (right - left)* height[left]
                left += 1
                max_area = max(cur_area,max_area)
            elif height[left] > height[right]:
                cur_area = (right - left)* height[right]
                right -= 1
                max_area = max(cur_area,max_area)
        return max_area
```

### 第二版：在分支后统一更新最大面积

```python
class Solution(object):
    def maxArea(self, height):
        """
        :type height: List[int]
        :rtype: int
        """
        left =  0
        right = len(height) - 1
        max_area = 0
        while left < right :
            if height[left] <= height[right]:
                cur_area = (right - left ) * (height[left])
                left += 1
            elif height[left] > height[right]:
                cur_area = (right - left ) * (height[right])
                right  = right - 1
            max_area = max(max_area,cur_area)
        return max_area
```

## 我的注释与感悟

将两版代码里的注释合并整理：

- **双指针从两端出发，相向移动。** `left` 从最左边开始，`right` 从最右边开始。只要 `left < right`，就还有两条不同的线可以组成容器。
- **先算当前面积，再移动较矮的一侧。** 如果左边的线不高于右边，就让 `left` 往右移；如果右边更矮，就让 `right` 往左移。我这两版在两边一样高时都选择移动左指针。
- **下标和高度要分开看。** `left < right` 比的是两个**位置**，用来判断是否继续循环；`height[left] <= height[right]` 比的是两条线的**高度**，用来决定移动哪边。
- **当前面积和历史最大面积分开记录。** `cur_area` 只记录这一对线的面积，`max_area` 保留到目前为止的最大值。第二版把两边重复的 `max(...)` 合成一处，遍历结束后返回 `max_area`。

## 知识点与评论

- **为什么能舍弃矮的一侧？** 假设左边较矮。如果保留这条左线、只把右线往里换，宽度会变小，水位又不可能超过左线的高度，所以面积不会超过刚算过的这一对。既然已经记下这一对的面积，就可以放心移动左指针；右边较矮时同理。
- **复杂度：** 每轮只移动一个指针，时间 `O(n)`，额外空间 `O(1)`。
