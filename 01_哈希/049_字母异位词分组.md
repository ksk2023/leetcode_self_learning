# 49. 字母异位词分组

**难度：** 中等 · **状态：** 力扣已解答 · [原题](https://leetcode.cn/problems/group-anagrams/)

## 题目

给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**示例 1：**

> **输入：** `strs = ["eat", "tea", "tan", "ate", "nat", "bat"]`  
> **输出：** `[["bat"],["nat","tan"],["ate","eat","tea"]]`
>
> **解释：**
>
> - 在 `strs` 中没有字符串可以通过重新排列来形成 `"bat"`。
> - 字符串 `"nat"` 和 `"tan"` 是字母异位词，因为它们可以重新排列以形成彼此。
> - 字符串 `"ate"`、`"eat"` 和 `"tea"` 是字母异位词，因为它们可以重新排列以形成彼此。

**示例 2：**

> **输入：** `strs = [""]`  
> **输出：** `[[""]]`

**示例 3：**

> **输入：** `strs = ["a"]`  
> **输出：** `[["a"]]`

**提示：**

- `1 <= strs.length <= 10⁴`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

## 我的答案

```python
class Solution(object):
    def groupAnagrams(self, strs):
        """
        :type strs: List[str]
        :rtype: List[List[str]]
        """
        ans =  {}
        for i in strs:
            key = "".join(sorted(i))
            if key not in ans:
                ans[key] = []
            ans[key].append(i)
        answer = ans.values()
        return answer
```

## 我的注释

> 字母异位词信息是字母组成和数量是一样的，但是顺序不一样。那么这样的话
> 得想一想怎么解决。
> 对于相同的组合，分开后肯定是一样的。因此这里肯定涉及到分开。然后下一步是将相同的存在一起。

## 知识点：`"".join(sorted(i))`

- `sorted("eat")` 得到排序后的**字符列表** `['a', 'e', 't']`；`"".join(...)` 用空分隔符把它拼成字符串 `"aet"`。
- `"eat"`、`"tea"`、`"ate"` 排序后都是 `"aet"`，所以共用一个字典键；分组里存的仍是**原单词**。排序会保留重复字母，因此 `"aab"` 和 `"abb"` 不会被误分到一组。

## 评论

分组思路正确。若使用 Python 3，`ans.values()` 返回的是视图而不是列表，要返回题目要求的列表可写 `return list(ans.values())`。上面保留截图中的原写法。
