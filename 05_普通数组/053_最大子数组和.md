# 53. 最大子数组和

**难度：** 中等 · **状态：** 力扣已解答 · [原题](https://leetcode.cn/problems/maximum-subarray/)

## 题目

给你一个整数数组 `nums`，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组**是数组中的一个连续部分。

**示例 1：**

> **输入：** `nums = [-2,1,-3,4,-1,2,1,-5,4]`  
> **输出：** `6`  
> **解释：** 连续子数组 `[4,-1,2,1]` 的和最大，为 `6`。

**示例 2：**

> **输入：** `nums = [1]`  
> **输出：** `1`

**示例 3：**

> **输入：** `nums = [5,4,-1,7,8]`  
> **输出：** `23`

**提示：**

- `1 <= nums.length <= 10⁵`
- `-10⁴ <= nums[i] <= 10⁴`

## 我的答案

### 第一版：Kadane 算法

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        #这里使用kandane算法
        cur_sum = 0
        max_sum = -inf
        for num in nums:
            cur_sum = max(cur_sum + num,num)
            max_sum = max(max_sum,cur_sum)
        return max_sum
```

### 第二版：区分当前最优与历史最优

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        # 肯定要维护一个全局变量和局部变量。局部变量是单个子数组内的和。
        cur_sum = 0
        max_sum = -inf

        for num in nums:
            cur_sum = max(num,num + cur_sum)

            max_sum = max(cur_sum,max_sum)
        return max_sum
```

第二版和第一版都是 Kadane 算法，`max(...)` 的两个候选项顺序不同，结果不变。注释里的「全局」指整个数组范围内的最优值；`cur_sum` 和 `max_sum` 在 Python 里都是函数的局部变量。

## 我的注释与感悟

- **每走到一个数，只考虑两种情况：接着之前的子数组，或者从当前数重新开始。** `cur_sum + num` 是接上当前数，`num` 是只取当前数。两者取较大值，得到**必须以当前位置结尾**的最大子数组和。
- **当前最优和历史最优分开。** `cur_sum` 必须以当前元素结尾，可能变小；`max_sum` 记的是所有已经扫过的终点里出现过的最大和。每轮先更新 `cur_sum`，再用它更新 `max_sum`，最后返回 `max_sum`。
- **判断要不要重开，看的是之前的累加和，不是当前数字是否为负。** 比如扫到示例 1 中 `4` 后面的 `-1`，接上它得到 `3`，比从 `-1` 重新开始更划算。接着加 `2`、`1`，就得到和为 `6` 的 `[4,-1,2,1]`。

## 知识点与评论

- **为什么只看这两个选项？** 以当前位置结尾的非空子数组，要么只有当前元素，要么是某个以紧邻的前一个位置结尾的子数组再加上当前元素。既然后一类都加同一个数，只需记住前一位置结尾的最大和，不必枚举所有起点。这就是 **Kadane 算法**。
- **全是负数时，答案也必须取到元素。** 例如 `[-5,-2,-7]` 的答案是 `-2`，不是 `0`。因此 `max_sum` 用负无穷初始化，而不是 `0`。原代码中的 `inf` 不是 Python 内置名称；独立运行时需先写 `from math import inf`，或把初始值写成 `float("-inf")`。上面保留原写法。
- **复杂度：** 扫描一遍数组，时间 `O(n)`，额外空间 `O(1)`。

### Kadane 的动态规划思路：延续，还是重新开始？

**状态定义：** `dp[i]` 是**必须以 `nums[i]` 结尾**的最大连续子数组和。`dp[0] = nums[0]`。到下标 `i` 时，要么接上前一段的最优结果 `dp[i - 1] + nums[i]`，要么只取当前数 `nums[i]`，从这里重新开始：

```text
dp[i] = max(nums[i], dp[i - 1] + nums[i])
```

**为什么只用两个变量？** 转移只依赖前一个状态，因此不用存整个 `dp` 数组。用 `cur_sum` 保存当前状态，再用 `max_sum` 记录遍历过程中见过的最大值：**`cur_sum` 回答「必须在这里结束，最好是多少」；`max_sum` 回答「可以在任意扫过的位置结束，最好是多少」。**

### 和股票最大收益的联系

这个思路可以用在**只买卖一次**的股票问题（第 121 题）：先把每天的价格换成相邻两天的**涨跌额**，而不是直接对股价求最大子数组和。一次交易的收益，就是从买入到卖出这段时间里涨跌额的连续和。对涨跌额跑 Kadane，走到每一天就比较：**沿用更早的买入点，还是只取今天相对昨天的涨跌额（昨天买、今天卖）？** 再用历史最大值记录最好的交易。

例如股价 `[7, 1, 5, 3, 6, 4]` 对应涨跌额 `[-6, 4, -2, 3, -2]`。最好的连续段是 `[4, -2, 3]`，收益是 `5`，对应 `1` 买入、`6` 卖出。**区别是：股票题可以不交易，所以收益最低是 `0`；第 53 题必须选非空子数组，全负时答案仍然是负数。**
