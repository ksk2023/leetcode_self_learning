# 238. 除了自身以外数组的乘积

**难度：** 中等 · **状态：** 力扣已解答 · [原题](https://leetcode.cn/problems/product-of-array-except-self/)

## 题目

给你一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除了 `nums[i]` 之外其余各元素的乘积。

题目数据 **保证** 数组 `nums` 之中任意元素的全部前缀元素和后缀的乘积都在 **32 位**整数范围内。

请 **不要使用除法**，且在 `O(n)` 时间复杂度内完成此题。

**示例 1：**

> **输入：** `nums = [1,2,3,4]`  
> **输出：** `[24,12,8,6]`

**示例 2：**

> **输入：** `nums = [-1,1,0,-3,3]`  
> **输出：** `[0,0,9,0,0]`

**提示：**

- `2 <= nums.length <= 10⁵`
- `-30 <= nums[i] <= 30`
- 输入 **保证** 数组 `answer[i]` 在 **32 位**整数范围内

**进阶：** 你可以在 `O(1)` 的额外空间复杂度内完成这个题目吗？（出于对空间复杂度分析的目的，输出数组 **不被视为** 额外空间。）

## 我的答案

### 第一版：分别记录前缀积和后缀积

```python
class Solution:
    def productExceptSelf(self, nums: list[int]) -> list[int]:
        #也就是说相同位置不乘
        ans =  [1] * len(nums)
        a = 1
        # 按照题意其实可以知道，这个是前缀积和后缀积，然后相同位置相乘即可。
        pre = [1] * len(nums)
        suf = [1] * len(nums)
        for i in range(len(nums)):
            # 先赋值，再乘当前元素：pre[i] 只记录 nums[i] 左边的乘积。
            # 如果 nums[0] = 2，先存 pre[0] = 1，再把 a 更新为 2，供下一轮使用。
            pre[i] = a
            a = a * nums[i]
        # print(a)
        a = 1
        for i in range(len(nums)-1,-1,-1):
            suf[i] = a
            a = a * nums[i]
        for i in range(len(nums)):
            ans[i] = pre[i] * suf[i]
        return ans
```

### 第二版：复用 `ans` 存前缀积

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        # 不要使用除法 7  /  2  =  3.5    <-- 浮点除法（保留小数）
       # 7 //  2  =  3      <-- 整除（只取整数商）
       # 7  %  2  =  1      <-- 取余数
    #   ans = []
    #   plus = 1
    #   for i,x in enumerate(nums):
    #     del nums[i]
    #     plus = plus * x
    #     ans[i] = plus
    #   return ans
    # 这里参考之前前缀和的思想，现在来做前缀积的情况
    # 算一个前缀积和后缀积
        ans = [1] * (len(nums)) #这样规定了ans答案数组的大小
        left = 1
        #首先计算前缀积 该数之前的前缀积*该数
        for i in range(len(nums)):
            ans[i] = left #对于第一个数，前缀积是1，跟前缀和一样是假设的。
            left = left * nums[i] #前乘积等于当前值乘以之前的乘积。下一个数的前缀积等于前一个数乘以该数的前缀积
        # ans现在是一个前缀积的列表，left表示当前数前一个数的前缀积
        #算后缀积
        right = 1
        for i in range(len(nums)-1,-1,-1):# range(start, stop, step)（遵循左闭右开原则：包含 start，不包含 stop），倒序进行遍历
            ans[i] = ans[i] * right
            right = right * nums[i] #right表示一个当前数后一个数的后缀积
        return ans
```

## 我的注释与感悟

- **第二版先把左侧积写进 `ans`，再倒序把右侧积直接乘回去。** `left` 和 `right` 在这里存的是累积乘积，不是下标。比如 `[1,2,3,4]` 正序扫完后，`ans` 是 `[1,1,2,6]`；倒序扫到 `i = 2` 时，`right` 是当前位置右边的积 `4`，所以先算 `ans[2] = 2 × 4 = 8`，再把当前的 `3` 乘进 `right`，留给下一轮。

- **「除了自己」就是把当前位置两侧的乘积相乘。** `pre[i]` 只乘 `i` 左边的元素，`suf[i]` 只乘 `i` 右边的元素，两者都不包含 `nums[i]`。所以最后直接用同一个下标：`ans[i] = pre[i] * suf[i]`。
- **算前缀积时，先赋值，再乘当前元素，顺序不能反。** 遍历到下标 `i` 时，`a` 只包含 `nums[i]` 左边的积。先用 `pre[i] = a` 记下这个值，再把 `nums[i]` 乘进 `a`，留给下一轮用。
  - **代入 `nums = [2,3]`：** 第一个数左边没有元素，所以先存 `pre[0] = 1`，再乘 `2`，得到 `a = 2`。到第二个数时，直接存 `pre[1] = 2`，所以前缀积是 `[1,2]`。
  - **如果先乘再赋值：** 第一轮就会写下 `pre[0] = 2`，把本来应该排除的 `nums[0]` 算进去了。
- **后缀积也是先存再乘。** 从右往左时，先写 `suf[i] = a`，再乘 `nums[i]`。开始算后缀积前，记得把 `a` 重置为 `1`。
- **后缀积要从最后一个下标倒着扫到 `0`。** `range(len(nums)-1,-1,-1)` 中，第一个参数是起点 `n - 1`，**第二个 `-1` 是不包含的停止值，为了让 `0` 也被访问到**，第三个 `-1` 表示每次减 `1`。例如 `n = 4` 时，依次得到 `3, 2, 1, 0`，共 `4` 个下标；如果停止值写成 `0`，就会漏掉下标 `0`。

## 知识点与评论

### 和前缀和的联系

前缀积和 [第 560 题「和为 K 的子数组」](../04_子串/560_和为%20K%20的子数组.md) 的前缀和用的是同一个思路：**用一个累积变量保留已经扫过的部分，不从头重算。** 第 560 题累加，空前缀和是 `0`，用两个前缀和相减得到区间和；本题累乘，空的一侧乘积是 `1`，把左右两侧的积相乘得到答案，不需要除法。

### 代入示例核对下标

以 `nums = [1,2,3,4]` 为例：

| `i` | `nums[i]`（不参与） | `pre[i]`（左边的积） | `suf[i]`（右边的积） | `ans[i]` |
|---:|---:|---:|---:|---:|
| 0 | 1 | 1（左边为空） | 24 | 24 |
| 1 | 2 | 1 | 12 | 12 |
| 2 | 3 | 2 | 4 | 8 |
| 3 | 4 | 6 | 1（右边为空） | 6 |

例如 `i = 2`，跳过 `3`，左边 `1 × 2 = 2`，右边只有 `4`，所以 `ans[2] = 2 × 4 = 8`。遇到 `0` 也不用特判：示例 2 只有下标 `2` 的结果排除了那个 `0`，其余位置的乘积都包含 `0`。

**两版复杂度对比（不计输出数组 `ans`）：**

- **第一版**扫描三遍，时间 `O(n)`；额外的 `pre` 和 `suf` 数组占用 `O(n)` 空间。
- **第二版**扫描两遍，时间仍是 `O(n)`；复用 `ans` 存前缀积，再用 `right` 滚动维护后缀积，额外空间降为 **`O(1)`**，满足进阶要求。
