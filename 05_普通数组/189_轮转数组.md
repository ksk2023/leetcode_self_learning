# 189. 轮转数组

**难度：** 中等 · [原题](https://leetcode.cn/problems/rotate-array/)

## 题目

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

**示例 1：**

> **输入：** `nums = [1,2,3,4,5,6,7], k = 3`  
> **输出：** `[5,6,7,1,2,3,4]`  
> **解释：**  
> 向右轮转 `1` 步：`[7,1,2,3,4,5,6]`  
> 向右轮转 `2` 步：`[6,7,1,2,3,4,5]`  
> 向右轮转 `3` 步：`[5,6,7,1,2,3,4]`

**示例 2：**

> **输入：** `nums = [-1,-100,3,99], k = 2`  
> **输出：** `[3,99,-1,-100]`  
> **解释：**  
> 向右轮转 `1` 步：`[99,-1,-100,3]`  
> 向右轮转 `2` 步：`[3,99,-1,-100]`

**提示：**

- `1 <= nums.length <= 10⁵`
- `-2³¹ <= nums[i] <= 2³¹ - 1`
- `0 <= k <= 10⁵`

### 第三种做法：三次反转

```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        k = k % n
        def reverse(left,right):
            while left < right:

                nums[left],nums[right] = nums[right],nums[left]
                left = left + 1
                right = right - 1
        reverse(0,n - 1)
        reverse(0,k-1)
        reverse(k,n-1)
```

## 我的注释与感悟

- **把反转封装进一个函数，用双指针从两端往中间交换。** `reverse(left, right)` 反转的是指定区间（含两端），不一定是整个数组。每轮先交换两端的元素，再让 `left` 加 `1`、`right` 减 `1`。
- **奇数长度：中间那个元素不用换。** 例如反转 `[1,2,3]`，交换下标 `0` 和 `2` 后，两个指针都到下标 `1`，循环停止，结果是 `[3,2,1]`。
- **偶数长度：最后一对换完，指针交叉就停。** 例如反转 `[1,2,3,4]`，先交换下标 `0` 和 `3`，再交换 `1` 和 `2`。此时 `left = 2`、`right = 1`，说明每一对都换完了，不是要反过来再换一次。**奇偶两种情况都用 `while left < right`。**
- **整段反转后按 `k` 分界，再分别反转。** 先让原来的后段到前面，再把前 `k` 个和剩下的元素各反转一次，恢复两段内部的顺序。这里“分段”只是传不同的下标范围，**不用切出新列表**。

- **把数组分成前段和后段，目标是从 `A + B` 变成 `B + A`。** 以 `n = 7`、`k = 3` 为例，前 `n - k` 个元素是 `[1,2,3,4]`，后 `k` 个元素是 `[5,6,7]`。这两段的顺序对调，段内的顺序不变。这个拆分思路没错。
- **分成两段不代表可以用旧下标原地交换。** 我原本想让后 `3` 个元素替换前 `4` 个，再把前 `4` 个放回后段。问题是第一次替换就让列表变短了，原来的切分点 `n - k` 已经不能定位现在的后段。
- **第二版先拼好「后段 + 前段」，再整体替换。** `nums[n-k:]` 取后 `k` 个元素，`nums[:n-k]` 取前 `n - k` 个元素。右侧两段先拼成一个和原列表等长的新列表，再用 `nums[:]` 一次写回。这样即使两段不等长，也没有第一次写回后下标变化的问题。
- **轮转前先取余，写回时保留原列表。** 转一整圈又回到原位，所以先用 `k % n` 把步数缩到 `0` 到 `n - 1`。余数为 `0` 时，后段 `nums[n:]` 为空，拼接后的顺序不变。`nums[:] = ...` 修改原列表的内容；如果写成 `nums = ...`，就只是把函数里的变量绑定到新列表，调用方的原列表不会变。

- **第三版先反转整个数组，再分别反转前 `k` 个和剩下的元素。** 整体反转已经把后段搬到了前面，但两段内部的顺序也反了；再各自反转一次，就能恢复段内顺序，得到「后段 + 前段」。
- **边界容易写错，就拿具体数字代进去。** `reverse(left, right)` 的两个下标都包含在区间内。以 `nums = [1,2,3,4,5,6,7]`、`k = 3` 为例：

| 步骤 | 闭区间 | 反转后的 `nums` |
|---|---|---|
| 整体反转 | `[0, 6]` | `[7,6,5,4,3,2,1]` |
| 反转前 `3` 个 | `[0, 2]` | `[5,6,7,4,3,2,1]` |
| 反转剩下 `4` 个 | `[3, 6]` | `[5,6,7,1,2,3,4]` |

## 错误案例与排查

- **输入：** `nums = [1,2,3,4,5,6,7]`，`k = 3`
- **实际输出：** `[5,6,7,5,1,2,3,4]`
- **预期输出：** `[5,6,7,1,2,3,4]`

Python 确实会先把右侧的两段切片都求出来；问题出在**左侧两个切片是从左到右依次写回的**。按这个顺序拆开看：

| 步骤 | 实际操作 | 操作后的 `nums` |
|---|---|---|
| 先算右侧 | 得到 `[5,6,7]` 和 `[1,2,3,4]`，原列表还没改 | `[1,2,3,4,5,6,7]` |
| 写入左侧第一个切片 | `nums[0:4] = [5,6,7]`，用 3 个元素替换 4 个 | `[5,6,7,5,6,7]` |
| 写入左侧第二个切片 | `nums[4:7] = [1,2,3,4]`。列表只剩 6 个元素，这个切片实际只替换下标 `4`、`5` 的 `[6,7]` | `[5,6,7,5,1,2,3,4]` |

**多出来的 `5` 是原后段的第一个元素。** 第一次赋值后它从下标 `4` 移到了 `3`，第二次却仍从下标 `4` 开始替换，于是它被漏在了原地。

## 知识点与评论

- **普通切片赋值允许两边长度不一样，不会因此报错，但会改变列表长度。** 这与 `nums[i], nums[j] = nums[j], nums[i]` 交换两个单独元素不同。两段碰巧等长时，第一次写入不挪动后段的下标，这也解释了为什么某些用例能通过。
- **`n+1` 不是这次错误的根因。** 切片的右端不包含在结果里，越过列表末尾会被截到末尾。在这个例子里，`nums[n-k:n+1]` 和 `nums[n-k:n]` 都取到 `[5,6,7]`；只改这个右端点，仍会因分两次写入而出错。
- **原地修改不等于只用常数额外空间。** 第二版符合原地修改 `nums`、不返回新列表的要求。不过右侧切片和拼接会创建临时列表，因此时间复杂度是 `O(n)`，额外空间也是 `O(n)`；如果要满足只用 `O(1)` 额外空间的进阶要求，这版还不够。
- **第四版注释里的 `return copy` 不是原地修改。** `(i + k) % len(nums)` 能算出元素的新位置，但只写入 `copy` 并返回它，不会改动调用方传进来的 `nums`。这段尝试保留在原注释里，不是第四版实际执行的逻辑。
- **第三版和第四版都不用创建切片。** 每次反转只用两个下标交换原列表的元素，总时间 `O(n)`，额外空间 `O(1)`。取余后如果 `k = 0`，`reverse(0, -1)` 不满足 `left < right`，不会访问下标 `-1`；其余两次都是整体反转，正好抵消。

## Python 核心知识点：切片、反转与迭代器

### 1. `nums[:]`：读切片是浅拷贝，写切片是原地修改

**`new_nums = nums[:]` 创建一个新的外层列表，但不复制里面的元素对象。** 这就是浅拷贝。替换新列表中的某个位置，不会改动原列表的对应位置：

```python
nums = [1, 2, 3]
new_nums = nums[:]
new_nums[0] = 99
print(nums)               # [1, 2, 3]
print(new_nums is nums)   # False：是两个列表对象
```

如果元素本身也是列表，两份外层列表仍然引用同一个子列表。**修改共享的子列表，原列表也能看到变化：**

```python
nums = [[1], [2]]
new_nums = nums[:]
new_nums[0].append(99)
print(nums)                     # [[1, 99], [2]]
print(new_nums[0] is nums[0])   # True：第一个子列表是共享的
```

**`nums[:] = ...` 替换原列表的内容；`nums = ...` 只是给变量重新绑定对象。** 用赋值前保存的 `original` 来验证，比对同一个变量写 `id(nums) == id(nums)` 更有用（后者始终为真）：

```python
nums = [1, 2, 3]
original = nums

nums[:] = [4, 5, 6]
print(original)               # [4, 5, 6]：原列表的内容变了
print(nums is original)       # True：还是原来的列表

nums = [7, 8, 9]
print(original)               # [4, 5, 6]：这次原列表没变
print(nums is original)       # False：nums 指向了另一个列表
```

回到本题，`nums[:] = nums[n-k:] + nums[:n-k]` **先在右边拼出结果，再用左边的切片赋值写回原列表**。如果左边只写 `nums = ...`，函数内的 `nums` 会指向新列表，调用方的原列表不变。右侧仍会创建临时列表，所以保留原对象不等于只用 `O(1)` 额外空间。

### 2. 反转列表的三种写法

**`nums[::-1]`：步长是 `-1`，从后往前取元素，返回新列表。** 原列表不变；元素本身仍然是原来的对象。

```python
nums = [1, 2, 3, 4]
new_nums = nums[::-1]
print(new_nums)   # [4, 3, 2, 1]
print(nums)       # [1, 2, 3, 4]
```

**`nums.reverse()`：原地反转整个列表，返回 `None`。** 不要写成 `nums = nums.reverse()`。

```python
nums = [1, 2, 3, 4]
result = nums.reverse()
print(nums)     # [4, 3, 2, 1]
print(result)   # None
```

**`reversed(nums)`：得到一个从后往前读取的迭代器，不会反转原列表。** 想要新列表时，用 `list(reversed(nums))` 是常见写法；如果只想倒序遍历，直接写 `for num in reversed(nums)` 就行，不必先转列表。

```python
nums = [1, 2, 3, 4]
print(list(reversed(nums)))   # [4, 3, 2, 1]
print(nums)                   # [1, 2, 3, 4]

it = reversed(nums)
print(next(it))   # 4：取出下一项，并推进迭代器
print(list(it))   # [3, 2, 1]：只收集剩余项
print(list(it))   # []：同一个迭代器已经取完了
```

**可以把迭代器理解成一个记住读取位置的游标。** `next()` 每次只取一项；`list()` 会把剩下的项全部取完。想从头再倒序读一次，要用 `reversed(nums)` 创建一个新迭代器。

### 3. 面试/笔试：不借助切片或内置反转，怎么手写？

**用相向双指针配合 `while`：交换两端指针指向的元素，再把两个指针各往中间移一格。** `left`、`right` 存的是**下标**，要交换的是 `nums[left]` 和 `nums[right]`。每交换一对，这两个位置就已经放好了，下一轮只处理内侧还没换过的部分。

```python
def reverse_range(nums: list[int], left: int, right: int) -> None:
    # 反转 [left, right]，两端都包含
    while left < right:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
        right -= 1


nums = [1, 2, 3, 4]
reverse_range(nums, 0, len(nums) - 1)
print(nums)  # [4, 3, 2, 1]
```

**用 `while left < right`：只要未处理的区间至少还有两个元素，就交换它们的两端。** 偶数长度时，最后一对换完，指针交叉；奇数长度时，指针在中间相遇，中间元素留在原位。例如 `[1, 2, 3, 4]` 只要交换下标 `(0, 3)` 和 `(1, 2)`；`[1, 2, 3]` 只需交换 `(0, 2)`。空区间或单个元素都不用换。

**整个列表和局部区间用的是同一个模板，区别只在初始下标。** 第 189 题依次传入 `[0, n - 1]`、`[0, k - 1]`、`[k, n - 1]`，不用真的把列表切成两份。第 344 题「反转字符串」给的是可修改的字符列表，只需用这个模板反转整个列表。长度为 `m` 的区间最多交换 `m // 2` 对，时间 `O(m)`，额外空间 `O(1)`。
